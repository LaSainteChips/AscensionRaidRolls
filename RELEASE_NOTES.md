## AscensionRaidRolls 1.8.0

### SR > MS > OS

- Added optional SR > MS > OS priority with BisBeard SoftRes/HardRes imports.
- Added multiple reservations for the same item with `1xSR`, `2xSR`, and reroll handling.
- Added synchronized SR settings, tooltip information, roster checks, reservation limits, and raid reminders.

### MS/OS+1 Loot Tracking

- Added synchronized MS/OS+1 tracking with separate MS and OS counters.
- Added manual corrections, history reset, and Top X winner handling.

### Trade Expiration Timers

- Added a compact trade-expiration window with color-coded progress bars and a 20-minute alert.
- Added item tooltips, Shift + Right-click roll selection, a Timers button, and `/rrtimers`.

### Options and Announcements

- Added a dedicated Options window for SoftRes, MS/OS+1, and automatic Master Loot settings.
- Added an option to silence winner raid-warning announcements.

### Interface and Compatibility

- Improved roll rows, SoftRes importing, timer layout, and viewer synchronization.
- Split the addon into logical modules for WoW 3.3.5a compatibility.
- Fixed Lua errors and synchronization edge cases.
